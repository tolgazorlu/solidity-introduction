# Solidity Introduction

A set of small Solidity contracts covering core language features, written while learning Solidity (2023-02).

## About

Course/learning repository: each contract isolates one language concept rather than solving a real problem.

## Contracts

- `Variables.sol` - state variable types
- `Operators.sol` - arithmetic, comparison and logical operators
- `Conditions.sol` - if/else control flow
- `Functions.sol` - function visibility and modifiers
- `Require.sol` - `require` based validation
- `Calculator.sol` - a basic calculator contract combining the above
- `Counter.sol` - a minimal increment/decrement counter
